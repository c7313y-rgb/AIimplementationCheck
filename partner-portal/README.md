# AI経営実装パートナーポータル（独立デモアプリ）

株式会社RCGをサービス提供者とする、取引先・金融機関／自治体・連携パートナーを権限別に分離した静的デモアプリです。

## ページと権限

| ロール | ページ | できること |
| --- | --- | --- |
| 取引先企業 | Client workspace | 経営インタビュー、AI導入適性、診断ID、次回面談事項の確認 |
| 金融機関・自治体 | Institution workspace | 紹介企業の進捗、最小限のサマリー、面談準備ステータスの確認 |
| RCG・連携パートナー | Partner workspace | 案件ポートフォリオ、連携先レジストリ、CSV出力、運用原則の確認 |

各ロールは個別のデモアカウントでログインし、未認証時はダッシュボードを表示しません。

## デモアカウント

| ロール | ユーザー名 | パスワード |
| --- | --- | --- |
| 取引先企業 | `client.demo` | `client2026!` |
| 金融機関・自治体 | `institution.demo` | `institution2026!` |
| RCG・連携パートナー | `partner.demo` | `partner2026!` |

ログイン情報はデモ体験のためブラウザのJavaScriptに含まれています。本番利用では必ずSSO／サーバー側認証へ置き換えてください。

## 提供体制

- サービス提供者：株式会社RCG（[公式サイト](https://rcg2020.co.jp/)）
- AI実装・導入支援：Edutex株式会社
- ご案内・伴走窓口：金融機関・自治体などの登録連携先

`partner-config.js` に提供者、実装パートナー、連携先を集約しています。将来の提携先追加は設定エントリを追加して行えます。画面には役割を必ず明記し、未登録名称をURLから直接表示しない設計です。

## データの扱い

- デモ認証・診断データは同一ブラウザの `sessionStorage` / `localStorage` のみを使用
- 外部LLM APIへの入力送信はありません
- 金融機関・自治体画面では取引先の回答全文を表示せず、診断IDと最小限の要約を共有
- 本番ではテナント分離、暗号化、監査ログ、同意・削除フローを追加

## ローカル起動

```bash
python3 -m http.server 4173
```

`http://localhost:4173/` を開いてください。

## GitHub Pages

このフォルダ単体をGitHub Pagesの公開ルートにできます。既存の診断アプリとは独立したアプリとして公開する場合は、`partner-portal/` を新規リポジトリのルートへ移し、Pagesの公開元を `main` に設定してください。
