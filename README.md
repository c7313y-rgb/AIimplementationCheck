# AI経営診断カルテ v2

中小企業の経営者・事業責任者を対象に、**経営上の意思決定プロセスからAI導入候補を発見する対話型診断アプリ**です。

## v2の位置付け

v1の18問式チェックを、経営者への自由記述インタビューを中心とする「AIインタビュー型診断」へ刷新しました。

単純なAI成熟度チェックではなく、次の情報を経営者の回答から構造化し、AI実装提案の起点を作ります。

- 経営者が実現したいこと
- 日常的に行っている重要な判断
- 判断基準
- 判断に使うExcel / PDF / メール / 基幹システム / 紙資料
- 判断頻度
- 1回あたりの所要時間
- 関与人数
- 判断が外れたときの損失
- 現在の属人化・検索・転記・集計等の課題
- AIに任せたい役割
- データ準備度
- 推進責任者
- PoC実施可能性
- 機密・規制リスク

## AIインタビューエンジン

GitHub Pagesでもそのまま動作できるよう、v2ではブラウザ内で完結する**適応型インタビューエンジン**を標準実装しています。

回答文からキーワード・数値・資料種別を抽出し、未取得情報だけを追加質問します。

### 抽出する主なシグナル

- 業務領域：営業 / 見積・原価 / 生産・施工・運用 / 顧客対応 / 管理業務
- 経営目的：売上 / 粗利 / 生産性 / 品質 / スピード
- データ種別：Excel / PDF / メール / 基幹 / CRM / CSV / 紙 / 画像 / 音声 等
- 頻度：月○回・○件
- 工数：○分 / 回
- 関与人数：○人
- 損失金額：○円 / ○万円
- 課題：属人化 / 検索 / 転記 / 集計 / ミス / 手戻り / 人手不足 等

## 診断結果

### 5軸スコア

1. 経営インパクト
2. AI適合性
3. データ準備度
4. 実装容易性
5. 推進条件

総合スコアを0〜100で算出し、以下の4段階で導入判断を表示します。

- 78〜100：積極導入を推奨
- 62〜77：限定業務からPoC推奨
- 45〜61：条件整備後に検証
- 0〜44：業務標準化を先行

### 診断カルテに表示する内容

- AI導入適性スコア
- AI化優先領域TOP3
- 推奨AI方式
- 診断根拠
- 月間削減時間の仮説
- 年間時間価値の仮説
- 失敗・手戻り削減余地
- 判断・情報収集時間の改善仮説
- 90日PoCロードマップ
- 次のAI提案・要件定義に引き継ぐ情報

## 効果推定について

効果額は保証値ではありません。

入力された以下の値からPoC前の初期仮説を算出します。

- 月間発生回数
- 1回あたり処理時間
- 関与人数
- 平均人件費 / 時間
- 判断ミス・手戻り損失

時間削減率は保守的なレンジとして20〜45%を用い、PoC後に実測値へ置き換える前提です。

## データ保存

回答データは標準状態ではサーバー送信せず、ブラウザの `localStorage` に保存します。

診断結果はJSONとして書き出せます。印刷機能を利用してPDF保存も可能です。

## 外部LLMとの関係

v2標準版は外部LLM APIを必須としません。これはAPIキーをブラウザに露出させず、GitHub Pages単体でも安全に動作させるためです。

将来、OpenAI等のLLMを利用する場合は、ブラウザから直接APIを呼ばず、Vercel Functions / Cloudflare Workers等のサーバー側エンドポイントを追加し、以下を置き換える設計です。

- 自由記述の構造化
- 回答内容に応じた追加質問生成
- 業種別ユースケース生成
- 診断カルテの自然言語要約
- PoC提案書 / 要件定義書の自動生成

## ファイル構成

- `index.html` — AIインタビュー、導入条件、診断カルテUI
- `styles.css` — レスポンシブUI / 印刷用CSS
- `script.js` — 適応型質問、自然文シグナル抽出、スコアリング、ROI仮説、JSON出力
- `README.md` — 設計仕様

## ローカル確認

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

## GitHub Pages

静的ファイルのみで動作するため、`main` ブランチをGitHub Pagesの公開元に設定できます。
