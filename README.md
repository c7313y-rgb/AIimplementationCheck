# AI経営診断カルテ

中小企業の経営者・事業責任者向けに、**AIを導入すべきか／どの業務から導入すべきか／どの程度の効果が見込めるか**を初期診断する静的Webアプリです。

## コンセプト

AIツールの機能比較から始めず、経営者の意思決定を起点に診断します。

1. 経営者が実現したいこと
2. AIに期待する役割
3. 重要な経営・現場判断
4. 判断基準と属人性
5. 使用している資料・データ
6. 情報収集・処理負荷
7. 過去判断の振り返り状況
8. 反復業務・品質ばらつき
9. データ準備度
10. PoC実施条件と情報リスク

## 診断仕様

- 18問 / 5診断軸
- 経営インパクト
- AI適合性
- データ準備度
- 実装容易性
- 経営・推進条件

総合スコアは上記を重み付けして0〜100で算出します。

### 結果区分

- 75〜100: 積極導入を推奨
- 58〜74: 限定業務からPoC推奨
- 42〜57: 条件整備後に検証
- 0〜41: 現時点ではAI優先度低め

## 診断カルテ出力

- AI導入適性スコア
- 5軸スコア
- AI化優先領域 TOP3
- 推奨AI方式
- 月間削減時間の初期推定
- 月間時間価値の初期推定
- 意思決定速度の改善余地
- 90日PoCロードマップ
- 次回AI提案時に取得すべき7項目

## 効果推定について

表示される時間・金額は、回答値と従業員規模を使った**営業前段階の仮説値**です。正式な投資対効果算定では、対象業務について以下を実測して再計算します。

- 月間処理件数
- 1件当たり工数
- 担当人数・人件費
- エラー率・手戻り率
- 売上・粗利への寄与
- AI利用料・開発費・保守費

そのため、本アプリの数値はROI保証値ではありません。

## ファイル構成

- `index.html` — UIと診断カルテ構造
- `styles.css` — レスポンシブデザイン
- `script.js` — 質問、採点、優先領域判定、効果推定、カルテ生成

外部ライブラリやAPIキーは不要です。

## ローカル起動

```bash
python3 -m http.server 4173
```

ブラウザで `http://localhost:4173` を開いてください。

## GitHub Pages

静的Webアプリのため、そのままGitHub Pagesで公開できます。

1. `main` にマージ
2. GitHub `Settings` → `Pages`
3. `Deploy from a branch`
4. Branch: `main`, Folder: `/ (root)`
